# 每个技能怎么用

以下提示词可直接给具有文件和命令权限的 agent。`$技能名` 用于 Codex；Claude Code 可改成 `/技能名`。将输入路径、研究问题及新输出目录换成实际内容。仅安装技能文件不等于安装它所调用的程序。

| 技能 | 用在什么地方 | 输入 → 输出 | 可复制提示词 | 详细步骤 |
| --- | --- | --- | --- | --- |
| `pdf-to-markdown` | PDF 原子转写及交付整理，或接收既有解析结果 | PDF、页范围、metadata/解析产物 → 原件、document.md、页映射、质量报告 | 用 $pdf-to-markdown 将这篇 PDF 转写到新目录，保存原件与 SHA256，说明缺页/扫描/乱序，抽查原 PDF。 | [用法](skills/pdf-to-markdown/references/usage.md) |
| `academic-docling` | 本地结构化解析、表格和布局来源 | PDF/文档 → Docling JSON、Markdown、图像与 provenance | 用 $academic-docling 解析这篇论文，保留原始 JSON 和页级 provenance，输出新目录；已选本地渠道。 | [用法](skills/academic-docling/references/usage.md) |
| `academic-mineru` | 扫描、公式、复杂学术 PDF 的另一解析渠道 | PDF、模式、页范围 → 原始解析目录、结构/布局、Markdown | 用 $academic-mineru 沿用我配置的渠道处理此 PDF；保留原始解析文件，核对 page_idx 与物理页。 | [用法](skills/academic-mineru/references/usage.md) |
| `academic-zotero-read` | 从已有 Zotero 取得文献及笔记线索 | 库查询、item key → 元数据、附件信息、批注、候选来源 | 用 $academic-zotero-read 找出 Zotero 库中与这个问题相关的材料，保留 item key 和批注位置，列出全文缺口。 | [用法](skills/academic-zotero-read/references/usage.md) |
| `academic-paper-search` | 用 Paper Search 的多源检索/可访问全文 | query、来源、筛选条件 → 文献候选、原始响应/下载记录 | 用 $academic-paper-search 搜索这个问题；列出来源和覆盖限制，把摘要命中与已有全文分开。 | [用法](skills/academic-paper-search/references/usage.md) |
| `academic-semantic-scholar` | Semantic Scholar 具体论文、作者及引文图查询 | query、paper ID、作者/图查询 → 原始 S2 JSON | 用 $academic-semantic-scholar 查询这篇论文的元数据和引用关系，保留 raw JSON，标出图谱推断。 | [用法](skills/academic-semantic-scholar/references/usage.md) |
| `academic-scholarqa` | 有检索计划、来源分级和候选 claim ledger 的研究收集 | 研究问题、多组 query → 资料集合与候选账本 | 用 $academic-scholarqa 分解这个问题并收集材料，按全文/摘要/元数据/图谱分级；未回到 PDF 的 claim 保持候选。 | [用法](skills/academic-scholarqa/references/usage.md) |
| `academic-paper-lookup` | 更直接的学术 API 检索和原始结果处理 | DOI/PMID/arXiv/query → 身份及检索记录 | 用 $academic-paper-lookup 检索这个主题，保存查询与原始响应，说明分页和去重；没有命中不能算反证。 | [用法](skills/academic-paper-lookup/references/usage.md) |
| `academic-citations` | 引用元数据、标识与 BibTeX 整理 | DOI/PMID/arXiv/引用记录 → 规范元数据、BibTeX、差异报告 | 用 $academic-citations 核对这些引用的元数据，合并同研究版本；单独列出需要全文确认的 claim。 | [用法](skills/academic-citations/references/usage.md) |
| `academic-critical-reading` | 理解研究设计、数值及局限 | 原论文、目标 claim → 方法/偏差/反例/边界笔记 | 用 $academic-critical-reading 阅读这篇论文，核对分母、效应量、混杂和适用边界，每项意见附原文位置或待查标记。 | [用法](skills/academic-critical-reading/references/usage.md) |
| `academic-hypotheses` | Science Dog 提出可检验的竞争假设 | 已核对观察、问题 → 假设、竞争解释、预测、负对照、ledger | 用 $academic-hypotheses 基于这些观察提出竞争假设和可区分预测，保留证据缺口，给出负对照及失败条件。 | [用法](skills/academic-hypotheses/references/usage.md) |
| `academic-literature-review` | Review Dog 综合/挑战已有材料 | 问题、范围、来源集合 → 搜索记录、纳排、证据综合及缺口 | 用 $academic-literature-review 对这个问题做综述，保存纳排理由、同源去重与相反结果，并给结论的支持边界。 | [用法](skills/academic-literature-review/references/usage.md) |
| `academic-peer-review` | 独立审阅 claim 与证据链 | 稿件、claim ledger、原来源 → 审查矩阵、问题与复核任务 | 用 $academic-peer-review 独立审查这份稿件，逐条检查 claim 的来源、反例和方法；区分结构通过与事实核对。 | [用法](skills/academic-peer-review/references/usage.md) |
| `academic-paperqa` | PaperQA2 的可选本地文库索引与问答 | 明确文库、已配置模型 → 派生答案及原件回溯待核表 | 用 $academic-paperqa 在我指定的文库中回答这个问题，先检查后端配置；引用回到原 PDF，摘要保持 AI 派生。 | [用法](skills/academic-paperqa/references/usage.md) |

## 常见选择

PDF 三个技能有不同分工：Docling/MinerU 是解析渠道，pdf-to-markdown 整理标准交付；按已有渠道选择即可。几个检索技能也可以择一使用，只有实际覆盖不足时再补源。同一篇论文的多路命中不会增加独立证据数量。

`academic-citations` 校验文献身份；`academic-critical-reading` 检查内容；`academic-peer-review` 审查 claim 链；三者的通过含义不同。假设技能的产物始终是待检验解释。Evidence Space、坐标和研究过程的分工见 [接入说明](证据边界与接入说明.md)。
