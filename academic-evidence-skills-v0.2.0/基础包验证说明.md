# 验证说明

日期：2026-10-12；AI 参与。验证范围为可携带技能、脚本行为和交付机制，不是解析准确率或科学结论认证。

## 实际执行

| 层次 | 检查内容 | 能支持的结论 |
| --- | --- | --- |
| 下载与来源 | 固定 commit、原始快照及文件哈希、许可证与配套资源 | 可以定位这次改编来自哪个上游版本 |
| 发现与结构 | 全部 14 个 SKILL 的官方 quick validator、目录/name、UI 信息、相对链接、Python语法和JSON | 技能包入口与必需资源完整；不证明任意客户端全部兼容 |
| 安装工具 | 9 项实际隔离测试，含预览、选择性复制、拒绝覆盖、篡改/未登记资源/路径穿越/软链接拒绝 | 在所测条件下避免覆盖已有技能，且不会自行安装依赖或联网 |
| PDF 转写适配器 | 先行 v0.1.0 的 17 项真实 CLI 机制测试；本包还做解压后的转移试跑 | 原件/hash、页范围、资产、拒绝覆盖、错误与 needs_review 机制可运行 |
| 科研脚本 | 保留 CLI 的离线帮助、候选 ledger/因果/审查/元数据/格式等实际离线行为，以及原 HTTP 返回的 mock 保存 | 测得这些本地机制与声明边界；不是实际 API 或引文真值核验 |
| 检索/问答 | 上游 mock 测试、CLI 参数核对、候选输出检查、PaperQA 离线 plan/doctor 和 mock query | 已测试输入/部分失败/候选标记机制；不是远端检索或模型质量认证 |
| 独立审查 | 由非编写该组的 agent 交叉检查调用、资源、边界与验证声明 | 可发现包内不一致；不替代真实材料或科学专家审阅 |

`verification-summary.json` 保存发布时的实际结果摘要。`manifest.json` 和 `tools/doctor.py` 用于本包文件完整性检查；SHA256 检查不等于软件签名或科学证据核验。完整运行日志和原始下载快照留在交付方内部档案，未把私人附件塞入包。

## 已知限制

本地 PDF classic 基线不做 OCR，扫描页可能没有正文；人工双栏样例出现阅读顺序及图注顺序问题，会交付 needs_review，原解析文本保持。数字、公式或表格看起来完整也需要回到 PDF 检查。导出成功和脚本退出 0 不证明语义正确。

未执行朋友真实 PDF、真实 MinerU/Docling 解析、真实 Zotero 库、Semantic Scholar/Paper Search/API 全源检索、PaperQA embedding/LLM 调用、Windows 环境或原工程 Registry/EU/Gate0/坐标集成。模型、渠道及授权配置需要在接收方实际环境验证；本包不会默换服务。

方法技能需要当前 agent 对真实来源进行阅读与判断。结构脚本只检查所声明字段，不能把填了 true 或填齐 locator 当作实际 verified。正式证据晋升需要独立回到来源核对，保留所查范围和未解决事项。
