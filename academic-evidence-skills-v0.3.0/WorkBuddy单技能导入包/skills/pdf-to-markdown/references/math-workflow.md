# 学术论文的公式转写与验收

2026-10-21 · 依据真实论文与参考稿的差异补充。这里只规定转换与核对，不新增正式 EU schema。

## 输入与目标

先区分忠实全文 `document.md`、版式友好的阅读副本和精读/总结。阅读副本可调整段落与标题，但不能省略图表/参考文献后仍声称全文；省略范围明确记录。现成样稿只能作为格式目标，需独立检查公式和内容覆盖后才能局部作为金标。

`reading_md` 不自动证明已经发生精读；Frontmatter 用真正的 `---`，列表和注释不加逃逸反斜杠。文章编号、页码、DOI、版本及 ID 作为字符串保存，尤其是以0开头的编号；未知书目信息保持null，不从文件路径猜作者或来源。示例 `article_number: "001234"` 不能写成无引号数字。

上述扩展书目字段用于阅读副本前言或原工程记录；本转换器 `--metadata` 仍使用既有白名单，不接收未知字段，不改变原工程的 schema。

## 选择执行后端

- 已有 MinerU/Docling 等产物：保留原生 JSON、模型/参数与页块定位，按既有外部页输入合同接入。必须确认实际启用了公式识别；文本层存在不等于数学结构可以直接提取。
- 内置 PyMuPDF4LLM classic：用于快速文本/图像基线。它在本次真实数学论文中未产出LaTeX片段，不能作为“公式完成”的依据。
- 本地公式模型：先测试分母嵌套、上下标、否定/不等式、矩阵元、离子电荷和能级，再扩展整篇。明确展示公式与行内数学的支持范围；不得把“展示公式可识别”推广为全文行内数学也已正确。
- 云服务：仅使用已有明确授权的渠道。保留原任务 ID 和原始响应；远端未知时观察原任务，不重复提交。不要以匿名入口或默认页窗口的结果冒充整篇。

具体 Docling 命令、依赖与本轮实际可运行范围见同包验证记录；未跑通的后端保持候选，不按宣传打精度排名。运行依赖/模型与此技能的许可分别核查。

## 转换与检查

接入有页级 provenance 的外部结果：

```sh
python scripts/convert.py /path/to/paper.pdf --output /path/to/new-bundle \
  --parser-pages /path/to/parser-pages.json --assets /path/to/parser-assets --require-latex
python scripts/verify.py /path/to/new-bundle --json
python scripts/math_check.py /path/to/new-bundle --require-latex \
  --output /path/to/new-bundle-math-check.json
```

没有图片目录省略 `--assets`。`--require-latex` 记录需求并保留 `needs_review`，不会启动公式OCR或自动修复公式，也不会取消原有 `quote_verified=false/l0_verified=false`。源公式核对以独立审查工件保存，不通过手改转换包来“变绿”。

分别记录：

1. **工程完整性**：原 PDF 哈希、请求/实际物理页、正文与图像产物；全篇与页子集分开。
2. **基本语法**：有无真实数学片段，分隔符和大括号是否明显残缺。代码里的 `$` 和转义美元不能充作公式。通过不等于完整LaTeX可编译。
3. **原图保真**：同一源页区域内的分子分母、括号作用域、指数/上下标、正负/不等号、矩阵索引、积分界、单位、化学计量和能级。能渲染的错误表达式也要拦下。
4. **覆盖与重复运行**：逐项对齐源公式/图表；只统计生成公式数会漏掉完全没识别的区域。同配置至少再跑一次代表范围，比较正文和数学结构；相同错误重复出现只是稳定，不能称为正确。

抽查清单同时保留源物理页、区域坐标基准、图像证据、转换片段、结论和修订记录。局部样本通过只支持已检查范围。原始转换不覆盖，修订副本保留发生改变的项；未知的符号、看不清的区域和解析失败明确留待复核，不依据学科常识补写。

## 坏定界符后的诊断恢复

全文实测发现一个坏美元定界符会使全局扫描错配后页。检查器在下一个既有物理页marker前仍未闭合时，报告跨页和未闭，再继续后页。它不插入/删除原文定界符，也不修复LaTeX或证明后页公式齐全；合法跨页公式同样保留待复核。词法片段计数与解析器原生数学区域数可能不同，不能用于准确率。
