# v0.1.0 验证范围

日期：2026-10-12。本地试验环境：Python 3.12.14，PyMuPDF/PyMuPDF4LLM 1.28.2。

17 项真实 CLI 机制测试通过：全文/子集、扫描/混合、加密拒绝、来源哈希、重复/缺页、图片存在与目录边界、已有输出拒绝覆盖、产物篡改、metadata 透传，以及 macOS 软链接输出目录。

测试使用人工可控的小型 PDF，未使用朋友真实论文，也未调用 MinerU/Docling 或云端。通过测试说明交付与降级机制有效，不表示真实论文精度已达标。

已知样例问题：本地 classic 在一页双栏中将左栏后的公式和脚注放到了右栏之前；图像仍保存，但图注可能出现在图片之前。该样例当前标 `needs_review`，保留原解析文本，不自动“修正”为原文证据。数字和 ASCII 公式保留不能证明复杂数学公式识别能力。

扫描件仅保留页图、没有正文，明确报告无 OCR。低文本和多栏启发式只提示复核，存在误报和漏报；复杂论文继续优先使用用户已有解析渠道，并回到原 PDF 比对。
